## Standard prompt set (built-in image-generation workflow)

Use case: scientific-educational. Asset type: two-panel FitLifeHub movement
tutorial at 3:2 landscape. Use `bench-press.webp` as a style reference only.
Generate a distinct illustration for the exact exercise name. Describe the
start position, finish position, camera view, equipment and anchor/hand/foot
placements from that exercise's written instructions. Preserve a consistent
graphite/violet athletic-suit avatar with cyan visor, dark navy glass cards,
cyan motion arrow, and translucent coral/magenta highlights on *only* the
listed primary target muscles. Same avatar and equipment across both panels.
No text, watermark, logo, exposed anatomy, unrelated equipment or generic pose.
Full relevant body and equipment visible; physically plausible movement.

Generate one distinct image per movement, inspect it at full resolution, and
regenerate or edit inaccuracies. Convert accepted PNG to WebP in the movement
folder, add its exact name to the manifest, and run `npm run check` before
packaging. Generation was performed with the built-in image tool; WebP
conversion used WebP quality 82. This is an incremental art project,
not a completed 860-image claim.
